Media keys need the xmonad bindings in =dotfiles/desktop/wm/xmonad.org=.

* Timing
- Home row mods: 200 ms hold, 250 ms on A R I O (pinky, ring).
- Chordal hold: a same-hand key while holding = tap; outer columns and thumbs
  are exempt (T + Backspace = Ctrl+Backspace).
- Flow tap: a home row key within 150 ms of a letter or Space = tap.
- Space: time only (no permissive hold), like kanata's Space layer on the laptop.

* Ideas for the free FN keys
Brightness ±, Print Screen, lock/sleep, Ctrl+←/→, Ctrl+Tab, clipboard,
mouse keys (MOUSEKEY_ENABLE), F13-F24 for own shortcuts, macros, LED controls.

#+TITLE: Voyager layout overview
#+DATE: 2026-10-28

Keep this in sync with =keymap.c=. =✗= = disabled key (=KC_NO=).
The Moonlander uses the same layers: =../moonlander-local/layout.org=.

* Layer 0: base (Colemak-DH)
#+begin_example
         outer  pinky  ring   middle index  inner │ inner  index  middle ring   pinky  outer
row 0    Lock   1      2      3      4      5     │ 6      7      8      9      0      Lay3
row 1    Tab    Q      W      F      P      B     │ J      L      U      Y      ;      Del
row 2    Esc    A      R      S      T      G     │ M      N      E      I      O      '
  (held)               Shift  Alt    Ctrl   Meta  │ Meta   Ctrl   Alt    Shift
row 3    ←      Z      X      C      D      V     │ K      H      ,      .      /      →

thumbs   upper: Space / FN   lower: Rpt / NUM     │ lower: Bksp / NUM   upper: Enter / Meta
#+end_example
Meta (xmonad mod) is in three places: hold G, hold M, or hold Enter.
Lock (top left, every layer, 2026-11-06) = Layer Lock: hold a layer key, tap
Lock to keep that layer on, tap Lock again to go back; it glows white while
locked. Holding it while plugging in still starts flash mode (bootmagic).
Lay3 (top right, 2026-11-07) = layer 3 (themes and media) on; tap it again to
go back. Macros: on layer 2, M1 (J position) = macro 1 and
M2 (L position) = macro 2 (2026-11-07). Hold ~quarter second = start recording
(key turns red), type, tap any macro key = stop; then tap = play it back.
Both macros share ~128 keystrokes and are lost when unplugged. Layer-key holds,
Lock and Lay3 are never recorded. Caps Word moved to both Shifts (hold R + I).
Lower thumbs (2026-11-06): tap left = Repeat (repeats the last key, e.g. for
double letters), tap right = Backspace (Shift + tap = Delete); hold either = NUM.
Esc is left of A (was Backspace; the top-left Esc became Lock). The thumb arrows
are gone; arrows are on the bottom corners and layer 2.

* Layer 2: FN (hold Space, blue)
#+begin_example
         outer  pinky  ring   middle index  inner │ inner  index  middle ring   pinky  outer
row 0    Lock   C-c a  C-c c  C-c d  C-c n  C-c s │ C-c i  C-c e  C-c f  C-<    ✗      BOOT
row 1    ✗      ←      ↓      ↑      →      C-x p │ M1     M2     F11    F12    C->    ✗
row 2    ✗      F1     F2     F3     F4     F5    │ F6     F7     F8     F9     F10    ✗
row 3    ✗      Home   PgDn   PgUp   End    ✗     │ C-c g  C-c v  C-c w  C-c k  C-c o  C-c l

thumbs   upper: [held]   lower: ✗                 │ lower: C-c r   upper: C-=
#+end_example
Emacs keys (2026-11-07, cyan in theme 1): Enter thumb = C-= (expand-region;
then = / - / 0), C-< (9) / C-> (;) = multiple-cursors mark previous / next.
C-c keys: =C-c a= sends C-c a, and so on, one key per prefix of the Emacs
config: a agenda, c capture, d codejot, n roam, s search, i files, e eshell,
f open-with, g magit / gptel, v avy, w elfeed, k calendar, o open / cursor,
l gptel / links, r smartparens (Backspace thumb). Hold Space, tap the key,
let go of Space, then type the command letter, e.g. Bksp thumb then j = C-c r j.
C-x p (B position, 2026-11-07) = the built-in project.el prefix, e.g. then f =
find file in project, p = switch project.
The themes, LED keys and media keys moved to layer 3 (2026-11-07).

* Layer 3: themes and media (tap Lay3, amber)
#+begin_example
         outer  pinky  ring   middle index  inner │ inner  index  middle ring   pinky  outer
row 0    Lock   Th1    Th2    Th3    Th4    Th5   │ LEDs   Brght  Dim    ✗      ✗      [back]
row 1    ✗      ✗      ✗      ✗      ✗      ✗     │ ✗      ✗      ✗      ✗      ✗      ✗
row 2    ✗      ✗      ✗      ✗      ✗      ✗     │ ✗      ✗      ✗      ✗      ✗      ✗
row 3    ✗      ✗      ✗      ✗      ✗      ✗     │ Mute   Vol-   Vol+   Prev   Play   Next

thumbs   upper: ✗   lower: ✗                      │ lower: ✗   upper: ✗
#+end_example
Tap the top-right key on the base layer to turn this layer on (it stays on);
tap it again ([back]) to go back to the base layer. Every other key is off
here, so nothing types until you go back.
Media keys need the xmonad bindings in =dotfiles/desktop/wm/xmonad.org=.
Th1-Th5 = LED themes, LEDs = all lights on/off, Brght/Dim = brightness
toggles (see LEDs below).

* LEDs (same on both boards)
- One colour per layer, set by the theme; theme 1: 0 green, 1 violet, 2 blue, 3 amber
  (brightness 150; highlights 230-255). Colours below are theme 1's.
- Themes: tap Lay3 (top right), then the top row picks one (kept after unplugging);
  each theme key glows in its theme's base colour.
  | Key | Theme         | Base    | Mods  | Layer 1 | Layer 2       | Layer 3 | Emacs  |
  |-----+---------------+---------+-------+---------+---------------+---------+--------|
  | 1   | Green + coral | green   | coral | violet  | blue          | amber   | cyan   |
  | 2   | Teal + coral  | teal    | coral | pink    | deep blue     | purple  | orange |
  | 3   | Las Vegas     | purple  | gold  | hot pink| electric blue | lime    | lime   |
  | 4   | Classic       | blue    | amber | indigo  | green         | teal    | cyan   |
  | 5   | Dark (ef)     | dim     | coral | dim     | dim           | dim     | cyan   |
  Key 6 turns all LEDs on/off (=RM_TOGG=); unplugging turns them back on.
  Key 7 = Bright toggle: every colour below 200 is raised to 200 (=BRIGHT_VAL=);
  brighter ones, like the mods, stay. Key 8 = Dim toggle: everything at 35%
  (=DIM_PERCENT=). One turns the other off; the active key glows white;
  the mode is kept after unplugging, with the theme.
  Colours: the =themes= table in =keymap.c=.
- Keys that are a modifier on hold on the base layer (R S T G, M N E I,
  Enter / Meta) are coral on the base layer. The firmware finds every =MT(...)=
  key in layer 0 at start-up, so a moved mod moves its colour.
- A mod key turns white while you hold it and its modifier is really on
  (every layer), so a hold that became Shift/Ctrl/Alt/Meta is easy to see.
- Emacs keys (layer 2: C-c keys, C-=, C-< and C->) have their own colour
  (Emacs column above).
- Layers 1-3 colour keys by group: numbers yellow, arrows white,
  Home/End/PgUp/PgDn white, F-keys yellow, media pink; symbols keep the
  layer colour. These win over coral, which is why coral is base-layer only.
- Caps Word (hold R + I together ~250 ms and let go): the letter keys are
  magenta
  on the base layer until Caps Word ends.
- Keys that are =KC_NO= on the current layer are off, so a held layer shows
  only its working keys. For a dim colour, change =LED_UNUSED= in =kind_colors=.
- QK_BOOT (layer 2, top right) is red.
- Macro keys (layer 2 M1/M2) are red while their macro records.
- The layer-tap thumb keys show the colour of the layer they open, brighter,
  on the base layer: Space blue (layer 2), Repeat and Backspace violet (layer 1),
  Lay3 amber (layer 3).
- All LEDs turn off after 5 minutes without a key press; the next key turns
  them back on and still types (=RGB_MATRIX_TIMEOUT= in =config.h=).

* Timing (same on both boards)
- Home row mods: 200 ms hold, 250 ms on R I (ring).
- Chordal hold: a same-hand key while holding = tap; outer columns and thumbs
  are exempt (T + Backspace thumb = Ctrl+Backspace).
- Flow tap: a home row key within 150 ms of a letter or Space = tap.
- Space: time only (no permissive hold), like kanata's Space layer on the laptop.
- Enter / Meta: 200 ms hold, permissive hold, no flow tap, so Meta works
  right after typing.

Brightness ±, Print Screen, lock/sleep, Ctrl+←/→, Ctrl+Tab, clipboard,
mouse keys (MOUSEKEY_ENABLE), F13-F24 for own shortcuts, macros, more C-c keys
(b, m, p are free prefixes), and the empty rows of layer 3.
